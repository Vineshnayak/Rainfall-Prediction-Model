# Rainfall Prediction (Machine Learning)

A Python project that predicts **whether it will rain** using historical weather data and machine-learning models.

## Tech Stack

Python · pandas · scikit-learn · NumPy · Matplotlib · Seaborn

## Files

* `RainfallPrediction.py` — main script
* `TrainingDatasetRainFallPrediction.csv` — training data
* `weather_testing_data.csv` — test data
* `predictions_output.csv` — model predictions
* `requirements.txt` — dependencies

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python RainfallPrediction.py
```

Predictions are saved to `predictions_output.csv`.
